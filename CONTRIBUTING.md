# Contribuire

PaceOS è in fase iniziale. Le modifiche devono essere piccole, verificabili e documentate.

1. Leggere README e documentazione in `docs/`.
2. Verificare licenza e provenienza dei componenti.
3. Creare backup e branch prima di modificare la base.
4. Non includere segreti, dati personali o artefatti di build.
5. Usare commit focalizzati e descrittivi.
6. Aggiornare CHANGELOG quando cambia comportamento o struttura.

Prima di proporre modifiche eseguire `git diff --check`, test pertinenti e `bash -n` sugli script shell. Non dichiarare build riuscite senza averle eseguite.
