# Sicurezza

Non pubblicare vulnerabilità, credenziali o dati sensibili nelle issue. Per segnalazioni riservate contattare il proprietario tramite un canale privato concordato.

- Non committare password, token, chiavi API o certificati privati.
- Usare file locali esclusi da Git e distribuire solo esempi senza segreti.
- Verificare provenienza e checksum dei componenti scaricati.
- Revisionare gli script privilegiati prima dell'esecuzione.
- Testare installer, kernel e ISO in VM.

PaceOS è in sviluppo e non è dichiarato idoneo a sistemi di produzione o dati critici.
