# Installazione

PaceOS non dispone ancora di una ISO pronta per l'installazione.

Quando sarà disponibile una build:
- verificare provenienza e checksum;
- provarla in macchina virtuale;
- controllare avvio live, rete, grafica e input;
- provare installazione e aggiornamento;
- predisporre un backup prima di qualsiasi test su hardware reale.
