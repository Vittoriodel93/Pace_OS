# Roadmap

- [x] Repository privata e documentazione iniziale.

## Fase 2 — Desktop

## Fase 3 — Applicazioni

- [ ] Strumenti sviluppatore e collegamento Android.

- [ ] Valutazione kernel e driver.
- [ ] Build ISO ripetibile.
- [ ] Test VM e hardware.
- [ ] Release con checksum e note.

Una fase si completa solo dopo implementazione, test riproducibile e documentazione.
