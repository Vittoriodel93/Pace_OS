# Roadmap PaceOS

## Versione 0.1.0 — Fondazione e prototipi
- [x] Repository privata e struttura iniziale.
- [x] Piano tecnico.
- [x] Scaffold Qt/QML consegnato e inserito in shell.
- [ ] Build Qt verificata sulla macchina di sviluppo.
- [ ] Importazione controllata della base AnduinOS 1.4.

## Fase 1 — Shell minimale
- [ ] CMake + Qt 6 compilabile e avviabile in sessione Wayland.
- [ ] Desktop con wallpaper, icone, taskbar e orologio.
- [ ] Finestre con drag, resize 8 direzioni, minimizza/massimizza/chiudi e snap.
- [ ] Tema chiaro/scuro, accent color e trasparenza.

## Fase 2 — App di sistema
- [ ] File manager, Impostazioni e Terminale.
- [ ] Centro notifiche e impostazioni rapide.
- [ ] Blocco note e visualizzatore immagini.
- [ ] Italiano e inglese.

## Fase 3 — Servizi
- [ ] paced e impostazioni persistenti via DBus.
- [ ] PaceAI con azioni locali controllate.
- [ ] Game Mode e overlay FPS.
- [ ] PaceCloud e PaceConnect.

## Fase 4 — Compatibilità e release
- [ ] PaceWin con Wine/Proton e Bottles.
- [ ] Installer e ISO avviabile.
- [ ] Store Flatpak e beta.

Arch è raccomandato dal piano tecnico come possibile base finale; AnduinOS 1.4 resta la base corrente finché non viene approvata una migrazione.
