# Ambiente di sviluppo

Le istruzioni definitive saranno aggiunte dopo aver verificato revisione e requisiti effettivi di AnduinOS 1.4.

## Regole
- Lavorare su branch dedicato.
- Conservare la directory originale fino a backup e confronto verificati.
- Annotare commit upstream, modifiche locali e dipendenze.
- Revisionare gli script con privilegi elevati.
- Eseguire build e test in VM.

## Prima integrazione
1. Rilevare branch, commit e remote locali.
2. Creare e verificare un backup.
3. Identificare il tag/commit upstream corretto.
4. Inventariare le personalizzazioni PaceOS già presenti.
5. Integrare senza perdere la cronologia o il lavoro locale.

I comandi specifici verranno definiti quando sarà disponibile la macchina di sviluppo.
